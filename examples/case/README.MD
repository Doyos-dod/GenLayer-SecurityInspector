Case Examples

This directory contains intentionally vulnerable or
demonstrative contracts used to validate the detection
capabilities of SecurityInspector.

Each contract is designed to trigger one or more
security rules and serves as a regression test for
future SecurityInspector releases.

Examples:
- SEC007-01-Missing-Access-Control
- SEC010-01-AI-Dependence
- SEC011-01-Unvalidated-AI-Decision

Purpose:
- Validate rule detection
- Prevent regression after updates
- Provide educational examples
- Demonstrate expected findings
